# LLM-ServeScope logo

Asset: `public/brand/servescope-logo.png`, a transparent PNG generated with the
built-in image generation tool. The source PNG is preserved without background
replacement or destructive editing. The header, footer, favicon and README use
this same asset; interface dimensions are set in CSS.

The emblem uses a scope frame and three scheduled flow paths in the dashboard's
navy/teal palette. The wordmark remains selectable HTML text for clarity and
accessibility. The logo is independent of the credited KAIST project identity.

## Final generation prompt

Use case: logo-brand. Asset type: final standalone application emblem for LLM-ServeScope, a professional engineering workbench for behavioral simulation of LLM serving. Create one distinctive, compact, flat geometric emblem on a genuinely transparent background. The mark should combine a clean angular S-shaped flow path with three parallel horizontal serving lanes and a precise open-frame scope silhouette, suggesting scheduled flow through compute resources. Strong, economical negative space, balanced square silhouette, substantial strokes that remain clear at 32 pixels. Palette: deep navy #102f43 and restrained teal #21886f, matching an existing white and pale blue technical dashboard. Premium scientific software identity, precise and calm. Center the emblem and let it occupy about 85 percent of a square canvas. No text, no letters as typography, no wordmark, no slogan, no mockup, no app tile or background rectangle, no gradient, no shadow, no glow, no neural-network dots, no brain, no microchip illustration, no decorative details. Deliver only a single finished emblem with crisp clean edges and transparent negative space.
